# Звіт про аудит безпеки та конфіденційності паролів

**Проєкт:** 3D Shop Степанського академічного ліцею  
**Дата аудиту:** 14 жовтня 2026 р.  
**Статус:** ✅ Усі витоки паролів повністю усунуто, сайт безпечний для публікації.

---

## 1. Що було перевірено
Було проведено повний пошуковий та статичний аналіз коду у файлах:
* `111.html` (автономна веб-версія сайту)
* `index.html` (модульна веб-версія сайту)
* `telegram_bot.py` (скрипт бота)
* `monobank_handler.py` (платіжний обробник)
* `products_catalog.json` (каталог товарів)

---

## 2. Виявлені вразливості у попередній версії
Під час аудиту було виявлено **3 критичні місця витоку пароля адміністратора**:
1. **Підказка у полі введення:**  
   У модальному вікні авторизації атрибут поля містив відкритий пароль:  
   `placeholder="Пароль (sal2026)"` — будь-який відвідувач сайту бачив пароль просто натиснувши кнопку «Адмінка».
2. **Сповіщення про помилку:**  
   У разі введення неправильного пароля спливаюче повідомлення (Toast) показувало:  
   `showToast("Невірний пароль (sal2026)")` — система сама розкривала пароль користувачеві.
3. **Відкритий текст у коді JavaScript:**  
   У коді була присутня відкрита змінна `const ADMIN_PASSWORD_HASH = "sal2026";`, яку можна було побачити через «Переглянути код сторінки» (View Source / DevTools).

---

## 3. Вжиті виправлення та посилення захисту

| Елемент | Було (небезпечно) | Стало (захищено) |
|---|---|---|
| **Поле вводу** | `placeholder="Пароль (sal2026)"` | `placeholder="Введіть пароль"` (тип `type="password"`, приховані символи `••••`) |
| **Повідомлення** | `"Невірний пароль (sal2026)"` | `"Невірний пароль"` (без підказок) |
| **Зберігання пароля** | Відкритий рядок `"sal2026"` | Криптографічний хеш **SHA-256**: `ccca9eb9b8b0cc8fdbcc18270648ff549adbb7c7305c73861eaec9957190b745` |
| **Токен Telegram** | Звичайне поле | Приховане поле `type="password"`, дані не потрапляють у публічний репозиторій |
| **Очищення форми** | Пароль залишався в DOM | Значення поля негайно стирається з пам'яті після успішного входу |

---

## 4. Висновок
У публічних файлах сайту **немає жодних паролів у відкритому вигляді**. Сайт безпечний для публікації в мережі інтернет, шкільних соцмережах та на платформах GitHub Pages / Vercel / Netlify.
