# Інструкція з налаштування Telegram-бота для замовлень 3D-магазину

Цей сайт підтримує **2 зручні способи отримання замовлень у Telegram**:
1. **Автоматична відправка через Telegram Bot API** — замовлення миттєво надходить у групу вчителів чи адміна одразу при натисканні клієнтом кнопки «Підтвердити замовлення» на сайті.
2. **Пряме замовлення в 1 клік через клієнтський чат** — покупець натискає кнопку в Telegram і сайт відкриває діалог із менеджером або ботом із уже сформованим та заповненим текстом замовлення.

---

## Варіант 1: Швидке налаштування на сайті (через Адмінку без сервера)

1. Відкрийте Telegram і знайдіть офіційного бота [@BotFather](https://www.google.com/search?q=https%3A%2F%2Ft.me%2FBotFather).
2. Надішліть команду `/newbot`, придумайте назву (наприклад, `Степанський ліцей 3D Shop`) та юзернейм (наприклад, `stepan_lyceum_3d_bot`).
3. Скопіюйте отриманий **Bot Token** (вигляду `7123456789:AAH...`).
4. Додайте створеного бота у вашу групу ліцею/гуртка (або почніть із ним приватний діалог).
5. Дізнайтеся ваш **Chat ID** (можна переслати будь-яке повідомлення з групи боту [@userinfobot](https://www.google.com/search?q=https%3A%2F%2Ft.me%2Fuserinfobot) або [@getmyid\_bot](https://www.google.com/search?q=https%3A%2F%2Ft.me%2Fgetmyid_bot)). Для груп ID зазвичай починається з `-100...`.
6. На сайті натисніть кнопку **«Адмінка»** у верхньому правому кутку (пароль: `sal2026`).
7. У блоці **«Telegram-бот для замовлень»**:
   - Вставте **Bot Token**;
   - Вставте **Chat ID**;
   - Вкажіть юзернейм вашого бота або менеджера (наприклад, `@stepan_3d_bot`);
   - Натисніть **«Зберегти налаштування»**, а потім **«Тест»**.
8. Готово! Усі наступні замовлення з кошика надходитимуть прямо у ваш Telegram-чат!

---

## Варіант 2: Запуск автономного Python-бота (`telegram_bot.py`)

У комплекті надано готовий файл `telegram_bot.py`, який працює на стандартному Python 3:

```bash
# Запуск бота:
python3 telegram_bot.py --token "ВАШ_ТОКЕН_БОТА" --chat "ВАШ_CHAT_ID"
```

### Можливості бота:
* Вітання нових клієнтів за командою `/start`;
* Перегляд повного інтерактивного каталогу виробів ліцею `/catalog`;
* Спеціальний розділ військових та волонтерських виробів для FPV-дронів `/fpv`;
* Інструкції та прийом замовлень `/order`;
* Перегляд списку останніх замовлень для адміністратора `/orders_list`.
